# static-pages

올머니 인터뷰용 프로토타입 3종을 GitHub Pages로 배포합니다.

- 그룹 1: https://huiyeon-yang.github.io/static-pages/group1/
- 그룹 2: https://huiyeon-yang.github.io/static-pages/group2/
- 그룹 3: https://huiyeon-yang.github.io/static-pages/group3/

주소 뒤에 `?task=2`, `?task=3`을 붙이면 해당 과업부터 시작합니다.
`main` 브랜치에 push하면 1~2분 뒤 자동으로 반영됩니다.
